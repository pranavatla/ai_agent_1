## When You Get Stuck

**Backend won't start?**
→ Check `pip install -r requirements.txt` worked
→ Check port 8001 isn't in use

**Frontend won't load?**
→ Check `npm install` worked
→ Check port 3000 isn't in use
→ Check `npm run dev` output

**CORS error?**
→ Backend CORS middleware is in main.py
→ Verify `NEXT_PUBLIC_API_URL` in .env.local

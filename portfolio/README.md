# atla.in

Sai Pranav Atla's portfolio. Next.js (App Router, static export), Tailwind CSS v4, Motion.

- `npm run dev` — local preview at http://localhost:3000
- `npm run build` — static site in `out/`, deployed to S3 + CloudFront by `.github/workflows/deploy-frontend-aws.yml` on push to `develop`

All copy and imagery lives in `src/lib/site.ts`.
